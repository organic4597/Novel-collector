# 북마크릿 요소 선택과 추출 프리셋

[대시보드 사용법](DASHBOARD.md) · [README](../README.md)

## 현재 기능

브라우저 확장 설치 없이 원본 HTTPS 페이지에서 마우스로 추출 영역을 선택합니다. 마우스 오버·테두리 강조·부모 요소 선택·미리보기·JSON 복사는 모두 **사용자의 원본 브라우저에서 처리**합니다. 서버 화면 캡처, 원격 마우스 좌표 전달과 매 hover API 요청을 사용하지 않습니다.

이 버전은 **프리셋 제작·검증·저장·불러오기** 단계입니다. 저장한 설정을 갱신 북마크릿으로 재사용할 수 있습니다. 자동 수집의 현재 DOM 파서에 프리셋을 적용하는 활성화 연결은 후속 단계입니다. 설정을 저장했다는 이유만으로 수집 원본이나 인증 세션을 변경하지 않습니다.

## 1. 등록

1. 대시보드에 로그인하고 **추출 프리셋** 메뉴를 엽니다.
2. 페이지 유형을 목록·소개·목차·본문 중 선택합니다.
3. **수집 영역 선택** 링크를 브라우저의 북마크바로 끌어 등록합니다.
4. 원본 사이트를 새 창/탭으로 열고 해당 북마크를 실행합니다.

끌어서 등록하기 어려우면 **북마크릿 코드 복사**를 눌러 새 북마크의 URL에 붙여 넣습니다. 클립보드 권한이 없으면 표시된 코드에서 Ctrl+C로 복사합니다. 주소창 붙여 넣기는 브라우저가 `javascript:`를 제거할 수 있으므로 북마크 URL을 사용합니다.

도구는 실행 함수 전체를 북마크 안에 포함합니다. 원본 사이트에서 대시보드 스크립트를 다운로드하거나 쿠키를 전송할 필요가 없습니다. 일부 사이트/브라우저의 보안 정책은 북마크릿 실행을 제한할 수 있습니다.

## 2. 영역 선택

- **선택 중:** 마우스 오버로 요소를 강조합니다. 클릭하면 현재 항목에 선택자를 지정하고 원본 링크의 클릭 동작을 막습니다.
- **부모 요소:** 글자나 이미지 대신 작품 카드·회차 행·본문 루트를 선택할 때 사용합니다. 부모를 고른 뒤 **이 요소 지정**을 누릅니다.
- **페이지 탐색:** 원본 페이지의 링크·버튼을 정상적으로 사용할 수 있습니다. 다시 선택 중으로 바꾸면 선택을 재개합니다.
- 다른 항목을 드롭다운에서 고르면 다음 요소를 선택할 수 있습니다.
- 헤더를 끌어 도구 위치를 옮길 수 있습니다. × 또는 Esc로 종료합니다.

원본에서 로그인·CAPTCHA가 필요하면 페이지 탐색 모드에서 정상적으로 확인합니다. 도구는 인증값이나 숨은 API 토큰을 수집하지 않습니다.

## 3. 유형과 항목

| 유형 | 지정할 항목 |
|---|---|
| 작품 목록 | 반복 카드, 제목, 작가, 장르, 태그, 공급처, 화수, 연재 상태, 표지, 링크, 업데이트, 다음 페이지 버튼 |
| 작품 소개 | 제목, 작가, 장르, 태그, 공급처, 화수, 연재 상태, 줄거리, 표지 |
| 회차 목차 | 반복 행, 회차 번호·제목·링크, 준비중 표시, 전체 화수, 더 보기 버튼 |
| 본문 | 본문 루트, 본문 텍스트, 로딩·오류 안내 |

속성은 `text`, `href`, `src`, `data-src`를 선택할 수 있습니다. 반복 카드/회차 행을 **먼저** 지정하면 그 안의 항목은 상대 선택자로 저장합니다. 태그처럼 여러 요소를 읽을 때는 여러 요소를 선택합니다.

Shadow DOM은 열린 root와 원본 렌더러가 유효한 `__novelShadow` 참조를 공개한 root를 처리합니다. 접근할 수 없는 closed root·다른 문서의 iframe 내부를 자동으로 열지는 않습니다. 동적 class/id와 좁은 `nth-of-type` 경로는 다른 샘플 페이지에서도 검증해야 합니다.

## 4. 미리보기와 저장

**전체 미리보기**에서 선택자가 실제로 어떤 값을 읽는지 확인합니다. 미리보기는 최대 5개 샘플과 제한된 텍스트만 표시합니다. **프리셋 JSON 복사**를 누르고 대시보드의 JSON 입력란에 붙여 넣어 저장합니다. JSON 파일 가져오기도 제공합니다.

저장 목록에서 **불러오기**를 선택하면 JSON 수정과 기존 프리셋 덮어쓰기를 할 수 있습니다. 함께 갱신된 북마크를 원본에서 실행하면 저장 선택자의 미리보기·재지정도 가능합니다. **JSON 보기**로 설정을 내보내거나 **삭제**로 제거할 수 있습니다.

프리셋은 로컬 `data/extraction-presets.json`에 저장합니다. 공개 Git에는 포함하지 않습니다.

## JSON 형식

```json
{
  "version": 1,
  "name": "작품 목록",
  "origin": "https://example.com",
  "pagePattern": "/novel",
  "kind": "listing",
  "fields": {
    "items": { "selector": "a.novel-card", "shadowPath": [], "attribute": "text", "multiple": true },
    "title": { "selector": ".nv-title", "shadowPath": [], "attribute": "text", "multiple": false, "relativeTo": "items" },
    "url": { "selector": ":scope", "shadowPath": [], "attribute": "href", "multiple": false, "relativeTo": "items" }
  }
}
```

`pagePattern`은 쿼리·hash 없이 경로를 저장합니다. `/novel/{workId}`, `/novel/{workId}/{episodeId}` 같은 패턴을 만들 수 있습니다. `shadowPath`는 바깥쪽 host부터 순서대로 지정합니다. `relativeTo`는 목록의 items 또는 목차의 rows에만 연결합니다.

서버는 지원 버전·필드·속성·origin·상대 경로·크기를 검증합니다. 최대 100개 프리셋, 한 설정 최대 32KiB, 저장소 최대 2MiB입니다. 샘플 원문, 쿠키, token/proof, JavaScript 코드와 입력값 읽기 속성은 가져오지 않습니다.

## API와 검증

- `GET /api/extraction-presets`: 요약 목록
- `POST /api/extraction-presets`: 새 설정 검증·저장
- `GET /api/extraction-presets/:id`: 설정 불러오기
- `PUT /api/extraction-presets/:id`: 수정 저장
- `DELETE /api/extraction-presets/:id`: 삭제

모두 관리자 인증을 거치며 수정 요청은 기존 출처 검사 정책을 사용합니다. Source picker가 대시보드에 직접 cross-origin 요청하지 않고 사용자가 JSON을 가져오는 구조입니다.

```sh
node --test tests/extraction-presets.test.mjs tests/element-picker.test.mjs tests/ui-extraction-presets.test.mjs
```
