## 1.0.0.15 릴리스 게시 확인 보완

1.0.0.14 후보는 GitHub의 전체 검증을 통과했지만, 초안 릴리스 업로드 직후 ZIP 체크섬 정보 확인에서 실패하여 운영에는 적용되지 않았습니다. 뒤에 확인한 GitHub 자산의 SHA-256, 후보 manifest, 첨부 SHA256SUMS의 ZIP 값은 동일했습니다. 정보가 아직 없는 경우의 제한된 재조회만 추가하고, 이미 존재하는 체크섬 불일치나 확인 시간 초과는 계속 실패 처리합니다. 기존 후보 태그·초안 자산을 덮어쓰지 않고 다음 버전의 검증과 업데이터 절차를 진행합니다.

게시 확인 회귀 검증은 digest 지연 생성 후 일치, 실제 불일치의 즉시 차단, 정보 부재의 제한된 실패를 확인했습니다. 보완 뒤 전체 **836/836 통과**했습니다.

1.0.0.15 후보의 CI는 기존 메타데이터 비동기 테스트가 150ms 안에 완료된다는 가정으로 실패했습니다. 완료 상태를 최대 2초까지 기다리되 같은 상태·재시도 횟수 검사를 유지하도록 시험 대기만 보완합니다. 수집기 로직이나 검증 기준을 완화하지 않습니다. 다음 정식 후보는 1.0.0.16입니다.
