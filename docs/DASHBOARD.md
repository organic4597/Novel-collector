# 로그인 후 이용 매뉴얼

[README](../README.md) · [설치·초기 로그인](INSTALL.md) · [프리셋](PRESETS.md) · [문제 해결](TROUBLESHOOTING.md)

이 문서는 현재 서점형 대시보드의 **실제 메뉴와 버튼**을 기준으로 설명합니다. 아직 설치하지 않았다면 [설치 안내](INSTALL.md)부터 진행하세요.

## 처음 사용할 때의 순서

1. **관리자 로그인**: 설치한 서버의 초기 접속 파일 또는 변경한 관리자 비밀번호로 로그인합니다.
2. **관리 → 설정**: 관리자 비밀번호를 변경하고 필요한 사이트 계정을 등록합니다.
3. **작품 찾기**: 소설·웹툰과 검색 조건을 고르고 작품을 선택합니다.
4. **수집 예약**: 회차 범위·예약 시각을 확인하고 수집 상황을 봅니다.
5. **작품 보관함**: 실제 저장된 회차를 읽거나 다운로드합니다.

로그인할 때 쓰는 **수집기 관리자 비밀번호**와 원본 사이트의 **아이디·비밀번호·PIN**은 별개입니다. 사이트의 추가 인증도 관리자 로그인만으로 완료되는 것은 아닙니다.

## 화면과 메뉴

| 위치         | 메뉴/버튼     | 용도                                         |
| ------------ | ------------- | -------------------------------------------- |
| 상단         | 작품 찾기     | 작품 검색·소개·여러 작품 선택                |
| 상단         | 작품 보관함   | 저장한 자료 읽기·다운로드                    |
| 상단         | 수집 예약     | 대기·수집 중인 작업 관리                     |
| 상단         | 수집 기록     | 완료·부분 실패·취소 기록                     |
| 관리 메뉴    | 추출 프리셋   | 선택자 설정·웹툰 원본 검증·수집 연결         |
| 관리 메뉴    | 설정          | 수집·화면·보안·서버·사이트 계정·업데이트     |
| 관리 메뉴    | 상세 로그     | 프로그램 요청·사용자 조작·오류·업데이트 진단 |
| 관리 메뉴    | 업데이트 내역 | 버전별 기능·개선·수정                        |
| 상단 아이콘  | 달·해         | 라이트·다크 모드 전환                        |
| 상단 아이콘  | 나가기        | 관리자 로그아웃                              |
| 연결 상태 옆 | 수집 로그     | 선택한 작품의 로그를 오른쪽에 열기/접기      |

좁은 화면에서도 네 작품 메뉴와 관리 메뉴를 사용할 수 있습니다. 관리 메뉴는 항목을 고르거나 Esc·바깥 클릭으로 닫습니다. 테마 선택은 브라우저에 저장되며 다른 탭과 동기화됩니다. 저장소가 차단된 브라우저에서는 현재 페이지의 전환은 동작하지만 재방문 때 선택이 유지되지 않을 수 있습니다.

## 관리자 로그인과 비밀번호

처음에는 설치 폴더의 `secrets/admin-login.txt`를 확인합니다. 파일은 **서버를 처음 실행할 때** 생성되며 사이트 계정 비밀번호가 아닙니다. 관리자 쿠키의 유효시간은 6시간이고 만료되면 다시 관리자 비밀번호로 로그인합니다.

**관리 → 설정 → 보안**에서 현재 비밀번호와 새 비밀번호·확인을 입력하고 **비밀번호 변경**을 누릅니다. 8~128자의 새 비밀번호를 사용합니다. 변경하면 초기 접속 파일은 삭제되고 다른 기기의 기존 관리자 로그인은 해제됩니다.

비밀번호를 잊으면 [로컬 웹 복구 또는 서버 관리자 수동 복구](INSTALL.md#관리자-비밀번호를-잊었을-때)를 따릅니다. 로그인 화면은 공개 주소에서 비밀번호를 보여주지 않으며 원격 주소의 초기화를 허용하지 않습니다.

## 사이트 계정 설정

1. **관리 → 설정 → 사이트 계정**으로 이동합니다.
2. **로그인할 수집 사이트**를 선택합니다. 각 사이트의 계정을 해당 항목에서 관리합니다.
3. 본인의 사이트 아이디·비밀번호·**숫자 4자리 고정 PIN**을 입력합니다. 처음 저장할 때는 비밀번호와 PIN이 모두 필요합니다.
4. **이 사이트의 자동 로그인 사용** 여부를 선택하고 **저장 및 자동 로그인 설정**을 누릅니다.
5. 필요하면 **로그인 및 2차 인증 실행**, **상태 확인**으로 결과를 확인합니다.

이미 저장한 계정을 편집할 때 비밀번호·PIN을 비워 두면 기존 값이 유지됩니다. 입력한 비밀번호와 PIN은 전송 직후 화면에서 지워집니다. 원본 사이트가 비밀번호/PIN을 바꾸거나 로그인·추가 인증을 다시 요구하면 상태 안내를 확인하세요.

**저장된 계정 정보 제거**는 해당 사이트의 저장된 자동 로그인 정보를 지우는 기능입니다. 확인 화면에서 대상을 확인하고 삭제합니다. 수집한 작품을 삭제하는 기능은 아닙니다.

### 사이트에서 추가 인증을 요구할 때

사이트 안내가 수동 확인을 요구하면 대시보드의 **CAPTCHA 풀기**에서 서버 화면을 엽니다. 사용자가 그 화면에서 직접 인증하고 **적용 및 수집 재개**를 누릅니다. 더 큰 조작 화면이 필요하면 **큰 인증창**을 사용합니다.

원본 사이트를 개인 PC의 별도 탭에서 여는 것은 서버 수집 브라우저와 다른 세션입니다. **수집하는 서버 세션의 안내 창**에서 완료해야 서버 작업에 적용됩니다. 로그인/PIN 입력과 사이트가 요구하는 추가 확인은 서로 다른 단계입니다. 해당 사이트의 요청 제한 대기는 인증과 별도로 유지될 수 있습니다.

## 작품 찾기

### 검색하고 소개 보기

1. **작품 유형**에서 소설 또는 웹툰을 고릅니다.
2. **검색 대상**을 작품 제목/작가 이름 중 선택하고 검색어를 입력합니다.
3. 장르·플랫폼·연재 상태·정렬을 선택한 뒤 **검색**을 누릅니다.
4. 표지나 제목을 누르면 소개 팝업에서 작가·장르·태그·줄거리·연재 상태·확인된 회차 수를 볼 수 있습니다.

웹툰은 **연재 중**과 **완결** 목록을 구분합니다. 일부 검색 조합·정렬은 원본 사이트가 제공하는 범위에 따라 제한됩니다. 안내 문구가 나오면 해당 조건을 조정합니다.

목록은 페이지당 최대 **40개 작품**입니다. 다음/이전으로 이동하며 저장 목록이 있으면 먼저 보이고 뒤에서 갱신될 수 있습니다. 조회 중 일부 작품부터 나타날 수 있고 실패 시 기존 목록은 유지됩니다.

회차 수의 최소·최대 필터는 **현재 페이지에서 확인한 정보**에 적용됩니다. **미확인 포함**을 끄면 회차 수가 아직 확인되지 않은 작품이 빠집니다. **선택 작품 회차 확인**으로 선택 항목의 정보를 다시 확인할 수 있습니다. 미확인 회차나 평점을 임의의 숫자로 표시하지 않습니다.

### 하나 또는 여러 작품 예약

- 한 작품: 소개 팝업의 저장 형식을 확인하고 **이 작품 수집 예약**을 누릅니다.
- 선택에 모으기: 소개 팝업의 **선택에 담기**, 또는 표지의 체크박스를 사용합니다.
- 여러 작품: 체크박스 또는 **보이는 작품 선택** → 저장 형식 → **선택 작품 대기 등록** 순서입니다. 한 번에 최대 **100개**를 선택합니다.
- **선택 해제**로 선택을 비웁니다. 소개 팝업을 닫아도 검색 조건과 목록 위치·선택은 유지됩니다.

소설은 TXT/EPUB을 선택합니다. 웹툰은 회차 CBZ·작품 ZIP 방식입니다. 같은 작품을 동시에 여러 슬롯에 중복 실행하는 것은 제한됩니다.

## 주소로 수집 예약

### 작품 하나

**수집 예약 → 작품 예약**에서 다음을 입력합니다.

| 입력                         | 의미                                                   |
| ---------------------------- | ------------------------------------------------------ |
| 작품 페이지 주소             | 작품 정보·회차 목록이 있는 실제 HTTPS 주소             |
| 예약 이름                    | 선택 사항. 비워 두면 작품 제목을 가져옵니다            |
| 시작/마지막 회차             | 비우면 전체 범위. 필요한 범위를 지정할 수 있습니다     |
| 예약 시각                    | 선택 사항·한국 시각. 비우면 수집 자리가 생겼을 때 실행 |
| 내보내기 형식                | 소설 TXT/EPUB, 웹툰 회차 CBZ·작품 ZIP                  |
| 이미 저장된 회차도 다시 수집 | 명시적으로 덮어써야 할 때만 선택                       |

회차 본문 하나나 목록 검색 페이지 대신 **작품의 정보·목차 주소**를 복사합니다. 사이트 호스트가 달라져도 지원하는 같은 작품 주소는 정규화되어 중복 등록을 제한합니다.

등록하면 작품 정보·표지가 먼저 보관함에 보일 수 있습니다. **작품 정보가 보이는 것과 본문/이미지가 저장된 것은 다릅니다.** 저장 회차가 없는 항목은 읽기·다운로드가 아직 활성화되지 않습니다.

### 여러 주소

**수집 예약 → 여러 주소 등록**에 한 줄에 작품 주소 하나씩 입력합니다. 한 번에 최대 **100개**이며 회차 범위·형식·예약 시각·덮어쓰기 옵션은 이 묶음의 공통 설정입니다. **대기 등록** 후 추가 결과와 중복/잘못된 주소 안내를 확인합니다.

## 수집 예약과 진행 상태

소설·웹툰 합계 **최대 두 작품**을 동시에 수집합니다. **관리 → 설정 → 수집**에서 한 작품으로 줄일 수 있습니다. 작품별 회차는 순차 처리합니다.

| 조작                              | 용도                                                      |
| --------------------------------- | --------------------------------------------------------- |
| 전체 시작                         | 전체 일시정지를 해제하고 실행 가능한 대기 작업 진행       |
| 전체 일시정지                     | 전체 수집을 일시정지. 진행 회차는 안전한 경계를 거쳐 반영 |
| 순서 위로/아래로 또는 카드 드래그 | 수집·대기·일시정지 작업의 우선순위 변경                   |
| 일시 중지/재개                    | 해당 작업을 중지하거나 이어서 진행                        |
| 취소                              | 해당 작업 수집 종료                                       |
| 예약 삭제                         | 예약을 목록에서 제거. 이미 저장한 작품 자료는 유지        |
| 로그                              | 해당 작품의 로그 선택                                     |

사용할 수 있는 버튼은 작업 상태에 따라 달라집니다. 수집 중인 순서를 바꾸면 현재 회차의 처리·저장 경계에서 새 순서를 확인합니다. 이후 재개할 때 이미 저장한 회차와 검증한 목차를 재사용합니다.

카드에서 저장/전체/기존/실패 수, 현재 회차, 단계, 진행률, 예상 남은 시간을 확인합니다. 예상 시간은 측정한 처리 속도를 사용하므로 네트워크·사이트 대기·인증에 따라 바뀔 수 있습니다. 표본이 부족하면 계산 중으로 표시합니다.

본문 없음·추출 실패는 해당 회차를 실패 목록에 남기고 다음 회차로 진행할 수 있습니다. 사이트가 HTTP 429/Retry-After로 요청 제한을 명시하면 대기 안내를 확인합니다. **전체 시작**은 그 제한이나 사이트의 추가 인증을 해제하는 버튼이 아닙니다.

## 수집 기록과 실패 재수집

완료·일부 실패·취소된 항목은 **수집 기록**에서 확인합니다. 상태 필터를 사용하고, 생성된 내보내기 파일이 있으면 해당 파일 버튼으로 내려받습니다. 소설 EPUB을 선택했다면 작업의 생성된 EPUB 내보내기를 이곳에서 확인합니다.

실패/누락 회차 재수집은 해당 버튼을 눌러 대상 회차를 확인하고 선택 후 새 대기에 등록합니다. 선택하지 않은 회차까지 일괄 덮어쓰는 기능과 구분합니다.

기록 삭제 후 해당 항목은 기록 목록과 작품별 로그 선택에서 빠집니다. 예약/기록 삭제는 보관함의 저장된 회차를 삭제하는 기능이 아닙니다. 상세 로그에는 사용자 조작에 대한 진단 기록이 별도로 남을 수 있습니다.

## 작품 보관함: 나의 서재

소설·웹툰 유형, 작품·작가 검색, 장르와 정렬로 저장 작품을 찾습니다. 카드의 **저장 회차 / 전체 회차**, 누락·실패·작품 정보 상태를 함께 확인하세요. 전체 회차가 미확인인 경우 완전 수집으로 단정하지 않습니다.

### 읽기와 한 작품 다운로드

| 종류      | 버튼과 결과                                              |
| --------- | -------------------------------------------------------- |
| 소설 읽기 | **회차 열기 →**에서 회차를 골라 저장된 본문 읽기         |
| 소설 합본 | **TXT 받기**: 현재 저장된 회차를 순서대로 합친 TXT 한 개 |
| 소설 EPUB | EPUB으로 수집한 작업의 **수집 기록**에서 생성 파일 확인  |
| 웹툰 읽기 | **회차 열기 →**에서 저장한 회차 이미지 읽기              |
| 웹툰 회차 | 읽기 창의 **회차 CBZ 받기**                              |
| 웹툰 작품 | **작품 ZIP 받기**: 저장 완료·검증된 회차 CBZ를 묶은 ZIP  |

다운로드는 **실제로 저장한 자료**를 사용합니다. 아직 저장하지 못한 회차를 파일에 포함시키거나 작품 전체 수집 완료로 취급하지 않습니다. 웹툰의 부분 저장/중단 회차는 완료 회차와 구분합니다.

표지는 기본적으로 전체 보기가 적용됩니다. **관리 → 설정 → 화면 → 표지 표시 방식**에서 틀 채우기로 변경할 수 있습니다. 표지가 없거나 불러오지 못하면 제목형 대체 표지가 표시됩니다.

### 여러 작품 다운로드

- **보이는 작품 선택**: 현재 페이지에서 다운로드 가능한 작품 선택.
- 표지 체크박스: 원하는 작품 선택.
- **전체 선택**: 검색 필터와 별개로 전체 보관 작품 중 다운로드 가능한 처음 **200개**를 선택.
- **선택 작품 ZIP 받기**: 선택한 작품을 묶음으로 준비.
- **전체 ZIP 받기**: 200개 선택 제한과 별개의 전체 저장 자료 묶음 요청. 기본 묶음 상한은 60,000작품·3GiB이며, 큰 보관함은 작품을 나눠 받습니다.

파일 준비 창에서 진행 상태를 보고 **ZIP 파일 받기**를 누릅니다. 창을 닫은 뒤 다시 확인할 때는 **ZIP 준비 상태**를 사용합니다. 선택/필터의 범위를 확인한 뒤 다운로드하세요.

## 설정

**관리 → 설정**의 항목별 바로가기를 사용합니다.

| 항목              | 설정/동작                                                                        |
| ----------------- | -------------------------------------------------------------------------------- |
| 수집              | 동시 작품 수 1~2, 회차 대기 500~10,000밀리초, 새 소설 예약 기본 TXT/EPUB         |
| 화면              | 갱신 간격, 보관함 페이지 크기 12/24/48/96, 표지 전체/틀 채우기, 여유/촘촘한 간격 |
| 빠른 설정         | 저부하·균형·기본값을 입력란에 적용한 뒤 저장                                     |
| 보안              | 관리자 비밀번호 변경·보기                                                        |
| 서버 정보         | 작업·작품·회차·저장 크기·디스크 여유·가동 시간·요청 대기 상태                    |
| 사이트 계정       | 사이트별 아이디·비밀번호·PIN 설정·로그인 실행·제거                               |
| 설정 파일         | 수집/화면 설정 JSON 내보내기·가져오기·미리 보기                                  |
| 프로그램 업데이트 | 정식·dev·핫픽스 선택·수정본 적용·작업 로그                                                |

수집/화면 입력은 **설정 저장**을 눌러 반영합니다. 빠른 설정이나 파일 가져오기는 입력란의 상태를 먼저 확인합니다. 동시 수집 수는 다음 작품 배정부터, 회차 대기 등 작업 설정은 새 작업부터 적용될 수 있으며 실행 중인 예약 설정을 무조건 덮어쓰지 않습니다.

설정 JSON에는 관리자/사이트 비밀번호가 포함되지 않습니다. 설정 파일을 가져오는 것은 본문·작품 DB를 가져오는 기능이 아닙니다. 현재 화면에 없는 AI 분류·소설 파일 대량 업로드 기능을 이 설정 파일 기능과 혼동하지 않습니다.

## 추출 프리셋

기본 수집이 동작하면 프리셋을 먼저 편집할 필요는 없습니다. 필요한 경우 **관리 → 추출 프리셋**에서 기본 템플릿의 독립 복사본을 추가하거나 원본에서 영역을 지정합니다.

**작성/서버 저장 → 세 페이지 원본 확인 → 수집에 적용**은 별도 단계입니다. 현재 실제 프리셋 실행 연결은 웹툰 수집에 적용됩니다. 소설 프리셋 작성·저장·검증·연결 API는 있지만 소설 수집 본문 경로는 내장 파서를 사용합니다. [상세 지원 범위와 단계별 안내](PRESETS.md)를 확인하세요.

## 로그 확인

### 작품별 수집 로그

예약/기록의 **로그**에서 작품을 고르고 상단 **수집 로그**로 오른쪽 창을 펼칩니다. 다른 작품을 고르면 새 로그를 즉시 조회합니다. **닫기/로그 접기**는 화면을 접는 동작이며 수집 중단과 다릅니다.

### 상세 로그

**관리 → 상세 로그**는 프로그램 요청·화면 조작·오류·업데이트 단계의 진단 기록입니다. 수준·동작·검색 필터, 실시간 갱신 멈춤, 새로고침과 이전 로그 더 보기를 사용합니다. 항목을 펼치면 상세 내용을 봅니다.

작품의 회차 진행·실패·추가 인증 상황은 작품별 수집 로그에서 확인합니다. 관리자/사이트 비밀번호·쿠키·토큰·본문 원문은 진단 기록 공유 대상으로 삼지 않습니다.

## 프로그램 업데이트와 버전별 내역

**관리 → 설정 → 프로그램 업데이트**에서 현재/최신 버전·마지막 확인을 보고 **업데이트 ▾**에서 정식·dev 실험판·핫픽스와 수정본을 선택한 뒤 같은 확인/적용 버튼을 사용합니다. 핫픽스는 정식 버전을 유지하며 적용 커밋을 표시합니다. 작업 로그는 준비·교체·재시작 단계와 오류를 표시합니다. 재시작 중 잠시 연결이 끊길 수 있습니다. [자료 보존과 실패 복구](UPDATE.md)를 확인하세요.

**관리 → 업데이트 내역**은 버전별 추가·개선·수정을 보여줍니다. 설정의 **버전별 변경 내역**, 상단 알림의 **변경 내역**도 같은 화면을 엽니다. 버전을 선택하거나 새로고침할 수 있고 개발 중인 내역은 별도로 표시합니다. 내역 조회 자체는 업데이트를 설치하지 않습니다.

## 사용 중 문제가 생기면

1. 실행 창 또는 서비스가 살아 있는지 확인합니다.
2. 관리자 로그인과 사이트 계정·추가 인증을 구분합니다.
3. 실패한 작업의 로그와 저장/전체/실패 수, 마지막 오류 문구를 확인합니다.
4. [문제 해결](TROUBLESHOOTING.md)의 해당 항목을 따릅니다.

자료를 지우거나 전체 덮어쓰기를 반복하기 전에 실패/누락 회차 재수집과 요청 대기·사이트 상태를 확인하세요.
## 작품 찾기 TOP 50와 보관함 상세

작품 찾기의 **일반 목록 / TOP 50 랭킹** 탭에서 조회 방식을 고릅니다. 랭킹은 시간별·일간·주간·월간과 웹툰·만화·소설을 제공합니다. 전체는 세 카테고리의 TOP 50을 모아 표시하며 카테고리별 원본 순위를 유지합니다.

랭킹 카드는 저장된 회차가 있으면 보관함 전용 팝업으로, 없으면 작품 찾기 소개 팝업으로 엽니다. 저장 여부는 로컬 저장 자료와 안정 작품 ID로 확인합니다.

보관함은 카드 자체를 클릭하거나 키보드 초점에서 Enter·Space를 눌러 엽니다. **작품 상세 정보** 탭은 저장 소개·작가·분류·상태를 즉시 표시하며 TXT/ZIP 받기·실패 회차 재수집을 제공합니다. **회차별 내용보기** 탭은 기존 회차 목록·텍스트·이미지·CBZ를 사용하고 필요한 회차 목록만 읽습니다. 체크박스는 팝업 열기와 별도로 작품 선택만 처리합니다.
