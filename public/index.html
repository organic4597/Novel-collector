추출 프리셋

확장 설치 없이 원본 페이지에서 요소를 고르고 선택자 JSON을 저장합니다.

프리셋 → 페이지 유형 → 추출 항목

프리셋 하나 안에 아래 세 페이지가 들어갑니다. ○는 미지정, ✓는 저장한 항목입니다. 정보 페이지의 위쪽 소설 정보와 아래쪽 회차 목록은 같은 유형입니다.

1. 페이지와 항목 선택

원본에서 항목 선택 → 영역 클릭 → ‘이 항목 저장’으로 고정합니다. 다시 항목을 고르면 고정 영역이 표시됩니다. 미리보기는 선택한 항목 값만 보여줍니다.

이 유형의 모든 항목을 이미지로 보기

2. 선택 도구 북마크 등록 · 최초 한 번

아래 링크를 북마크바로 끌어 등록하세요. 같은 브라우저 프로필의 새 창에서도 등록한 북마크를 사용할 수 있습니다. 위 유형·항목은 새로 등록할 북마크의 초기 설정이며, 원본의 선택 도구 안에서도 변경할 수 있습니다.

수집 영역 선택

마우스 오버·강조·미리보기는 원본 브라우저에서 처리합니다. 쿠키·입력값·본문 원문은 저장 JSON에 포함하지 않습니다. 일부 사이트의 보안 정책은 북마크릿 실행을 제한할 수 있습니다.

브라우저 정책상 웹앱이 북마크를 자동 등록하거나 다른 사이트에서 자동 실행할 수는 없습니다. 등록은 한 번, 실행은 원본 창에서 북마크 클릭 한 번이면 됩니다. 이미 등록한 북마크는 위 설정 변경으로 자동 갱신되지 않습니다.

3. 링크로 원본 열기

링크를 입력하면 사용자 브라우저의 새 창/탭에서 원본을 직접 엽니다. 원본의 기존 로그인 상태를 사용하며 화면 캡처나 서버 원격 조작을 거치지 않습니다.

창이 열리지 않으면 원본 직접 열기

열린 원본 탭에서 ‘수집 영역 선택’ 북마크를 눌러 시작하세요. 북마크바가 보이지 않으면 Ctrl+Shift+B (Mac: ⌘+Shift+B)로 표시하거나 브라우저의 북마크 메뉴에서 실행하세요.

4. 프리셋 서버 저장

원본에서 필요한 항목을 모두 고정한 뒤 ‘프리셋 서버 저장’을 누르면 이 대시보드로 설정을 전달해 저장합니다. 원문 미리보기는 보내지 않습니다. 로그인 상태에서 이 브라우저가 등록한 북마크의 저장 연결을 사용합니다.

설정 JSON 직접 가져오기 · 고급
