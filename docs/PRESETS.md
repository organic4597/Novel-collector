# 추출 프리셋 사용 안내

[처음 설치하기](INSTALL.md) · [대시보드 사용법](DASHBOARD.md) · [문제 해결](TROUBLESHOOTING.md) · [README](../README.md)

프리셋은 원본 페이지에서 **어떤 영역을 작품 카드·제목·회차·본문으로 읽을지** 정하는 설정입니다. 관리자 로그인 후 상단 **관리 → 추출 프리셋**에서 사용합니다.

## 1. 처음 사용할 때 알아둘 점

일반적인 수집은 내장 설정으로 시작할 수 있습니다. 사이트 구조가 바뀌거나 가져올 항목을 조정할 때 사용자 프리셋을 만드세요.

| 단계                                        | 하는 일                           | 수집 설정 변경                  |
| ------------------------------------------- | --------------------------------- | ------------------------------- |
| 기본 프리셋 **추가**                        | 수정 가능한 독립 복사본 생성      | 없음                            |
| 원본 도구의 **이 항목 저장**                | 현재 브라우저에 선택자 고정       | 없음                            |
| **프리셋 서버 저장** / **프리셋 수정 저장** | 서버에 설정 보관                  | 없음                            |
| 목록·작품 정보·본문 **원본 확인**           | 서버에서 선택자 매칭 확인         | 없음                            |
| **수집에 적용**                             | 해당 사이트·유형의 기본 연결 변경 | 웹툰의 새 수집에 반영           |
| **적용 해제**                               | 사용자 기본 연결 제거             | 웹툰의 새 수집은 내장 설정 사용 |

**현재 실행 범위:** 웹툰 작품 찾기·정보 조회·신규 예약·본문 이미지 수집은 프리셋 실행 경로에 연결되어 있습니다. 소설 프리셋도 작성·저장·원본 확인·기본 연결 기록을 지원하지만, **현재 소설 수집은 내장 파서를 사용합니다. 소설 프리셋을 적용해도 소설의 실제 수집 선택자는 바뀌지 않습니다.** 화면에 표시되는 적용 상태와 실제 수집 경로의 지원 범위를 구분하세요.

지원하는 원본 사이트의 선택자를 조정하는 기능입니다. 임의의 사이트를 등록하면 로그인·검색·수집을 모두 자동 지원하는 범용 크롤러는 아닙니다.

## 2. 기본 설정 복사해서 시작하기

1. **수집할 작품**에서 **소설** 또는 **웹툰**을 선택합니다.
2. **기본 프리셋**에서 사용할 원본의 설정을 고르고 **추가**를 누릅니다.
3. 현재 항목은 `sbxh9 소설 기본`, `toki32 소설 기본`, `sbxh9 웹툰 기본`, `toki32 웹툰 기본`입니다. 선택한 유형의 항목만 표시됩니다.
4. 새 복사본이 편집 화면에 열립니다. **프리셋 이름**을 정하고 아래 원본 선택·저장·확인 절차를 진행합니다.

같은 기본 설정을 다시 추가해도 기존 프리셋을 덮어쓰지 않으며 별도 이름과 ID로 보관합니다. 추가만으로 활성 연결을 바꾸지 않습니다. 직접 시작하려면 **새 프리셋 작성**을 사용합니다. 저장한 프리셋이나 항목을 이미 지정한 초안의 유형은 바로 바꿀 수 없습니다. 다른 유형은 새 프리셋에서 작성하세요.

## 3. 세 페이지와 지정 순서

| 페이지 유형                    | 소설 경로 예시                | 웹툰 경로 예시                  | 먼저 고를 영역                       |
| ------------------------------ | ----------------------------- | ------------------------------- | ------------------------------------ |
| 작품 목록 (`listing`)          | `/novel`                      | 연재 `/ing`, 완결 `/end`        | 작품 카드 한 개와 반복 설정          |
| 작품 정보·회차 목록 (`detail`) | `/novel/{workId}`             | `/webtoon/{workId}`             | 작품 제목, 회차 행 한 개와 반복 설정 |
| 회차 본문 (`reader`)           | `/novel/{workId}/{episodeId}` | `/webtoon/{workId}/{episodeId}` | 광고·메뉴를 제외한 본문 루트         |

작품 정보와 회차 목록은 같은 페이지 유형입니다. `{workId}`·`{episodeId}`는 작품·회차 ID 자리이며, 원본 확인에는 중괄호 패턴 대신 **실제 주소**를 입력합니다. 페이지 패턴에는 쿼리·인증값을 넣지 않습니다. 화면의 그림은 항목 안내용 합성 그림으로 실제 캡처가 아닙니다.

- 목록에서 **작품 카드 (먼저)**를 저장하고 내부 제목·작가·표지·작품 링크를 지정합니다. 전체 목록 대신 카드 한 개의 공통 구조를 고르고 **여러 요소**를 사용합니다.
- 작품 정보에서는 작품 제목·줄거리와 회차 제목을 구분합니다. **회차 행 (먼저)**을 저장하고 행 안의 회차 표시·제목·본문 링크를 지정합니다.
- 반복 부모를 먼저 고정하면 내부 항목이 상대 선택자로 연결됩니다. 카드·행을 교체하거나 지웠다면 내부 항목도 다시 확인합니다.
- **다음 페이지 버튼**, **더 보기 버튼**은 반복 영역 밖의 독립 동작입니다. 실제 페이지 이동·추가 회차 표시 버튼 하나를 지정합니다.
- 소설은 **본문 루트**와 실제 **본문 텍스트**를 지정합니다. 소개·댓글·광고를 포함하지 않습니다.
- 웹툰은 **웹툰 본문 루트 (먼저)**를 고정한 뒤 **웹툰 이미지**를 지정합니다. 원본 도구에서는 **이미지 본문 루트**, **본문 이미지 (반복)**으로 표시됩니다. `imageUrl` 속성과 **여러 요소**를 사용하며 본문 루트에 상대 연결됩니다. 루트 안의 기본 `img` 선택자가 이미지 하나의 고유 ID나 로딩 상태 때문에 다른 컷을 놓치지 않는지 확인합니다.

웹툰에서는 **연재 목록 경로**, **완결 목록 경로**, **검색 경로 (선택)**, **원본 목차의 표시 순서**도 확인합니다. 최신화가 위라면 **최신 회차부터**, 1화가 위라면 **첫 회차부터**입니다. 전체 회차 수와 목차 이동이 잘못 지정되면 완전성을 확인할 수 없어 수집이 실패할 수 있습니다.

## 4. 원본 브라우저에서 영역 선택하기

사용자의 일반 브라우저 새 탭에서 진행하며 서버 원격 화면·원격 마우스를 사용하지 않습니다.

1. 페이지 유형과 **지정할 항목**을 선택합니다.
2. **수집 영역 선택** 링크를 북마크바로 끌어 등록합니다. 또는 **북마크릿 코드 복사**로 브라우저의 새 북마크 주소에 붙여넣습니다. 코드의 `javascript:`가 남아 있는지 확인합니다.
3. **원본 HTTPS 페이지 링크**에 실제 주소를 넣고 **원본 새 탭 열기**를 누릅니다. 탭이 막히면 **원본 직접 열기**를 사용합니다.
4. 원본 탭에서 등록한 북마크를 실행합니다. 원본 로그인·본문 접근에 필요한 절차는 사이트에서 정상적으로 완료합니다.
5. 원본 도구에서 항목을 고르고 해당 영역을 클릭합니다. 노란 테두리는 아직 저장하지 않은 후보입니다.
6. **이 항목 저장**을 누릅니다. 저장한 항목은 초록 테두리로 확인합니다.
7. 다른 항목·페이지에서도 지정합니다. 원본 링크를 누르려면 **선택 중** 버튼으로 **페이지 탐색** 모드로 전환합니다.
8. 원본 도구의 **프리셋 서버 저장**을 누릅니다. 대시보드 저장 화면이 새 탭으로 열리며 서버 저장 완료 메시지를 확인합니다.

북마크바는 Windows/Linux `Ctrl+Shift+B`, macOS `⌘+Shift+B`로 표시합니다. 대시보드가 북마크를 자동 등록하거나 다른 사이트에서 자동 실행할 수는 없습니다.

**부모 요소**로 바깥 영역을 고르고 다시 저장할 수 있습니다. 도구 제목을 끌어 위치를 옮깁니다. 항목을 다시 선택하면 고정 영역이 복원되며 제거 버튼으로 선택자를 지웁니다. `Esc`나 ×로 닫아도 브라우저에 저장한 선택자는 남습니다.

**선택 항목 미리보기**는 현재 항목의 값만 최대 5개, 초록 강조는 최대 20개입니다. 화면 부하 제한이며 실제 회차·이미지 수집 개수 제한이 아닙니다.

### 브라우저 권한·저장 연결

- 원본 도구와 대시보드 연결은 각각 자기 사이트의 `localStorage`를 사용합니다. 브라우저 저장을 차단하면 고정·서버 반환이 실패할 수 있습니다.
- 원본 저장은 대시보드 URL의 fragment로 선택자 JSON을 반환합니다. 원본에서 대시보드 API를 직접 호출하지 않으며 읽은 fragment는 주소에서 제거합니다.
- 저장 연결은 최대 **24시간**이며 로그아웃하면 폐기됩니다. 원본 origin·유형·형식 버전을 확인합니다. 만료되면 대시보드에서 현재 북마크를 다시 등록하거나 JSON으로 가져옵니다.
- 반환에는 같은 브라우저의 대시보드 저장 공간이 필요합니다. 다른 브라우저·프로필로 옮길 때는 **설정 JSON 복사**와 아래 가져오기를 사용합니다.
- 사이트의 CSP·브라우저 정책이 북마크릿을 막을 수 있습니다. 전체 보안 설정을 해제하는 대신 허용된 정상 브라우저 환경이나 JSON 편집 방법을 사용합니다.
- 원본 탭의 로그인은 서버 수집 브라우저로 자동 복사되지 않습니다. 프리셋 저장은 인증 세션을 옮기는 기능이 아닙니다.

## 5. 저장 → 세 페이지 확인 → 적용

1. **저장한 프리셋**에서 **불러오기**를 누릅니다.
2. 편집했다면 **프리셋 수정 저장**을 먼저 누릅니다. 미저장 상태에서는 확인·적용이 잠깁니다.
3. **원본 확인 후 수집에 적용**에 같은 사이트의 실제 목록·작품·회차 주소를 입력합니다.
4. **목록 원본 확인**, **작품 정보 원본 확인**, **본문 원본 확인**을 각각 실행합니다. 항목별 매칭 개수를 확인합니다.
5. 최신 설정으로 세 페이지 모두 확인한 뒤 **수집에 적용**을 누릅니다.
6. 적용된 설정을 사용할 웹툰 예약은 이후 새로 만듭니다.

확인은 서버의 원본 접근·필수 영역 검증입니다. **현재 확인기는 별도의 Chromium 컨텍스트를 사용하며 사용자 브라우저나 기존 수집 브라우저의 로그인·인증 쿠키를 그대로 사용하지 않습니다.** 다른 탭에서 본문이 보여도 인증이 필요한 페이지의 서버 확인은 실패할 수 있습니다. 저장만으로 검증이 완료되거나 사이트 인증이 해결되지 않습니다.

| 페이지              | 실행 필수 항목                                       |
| ------------------- | ---------------------------------------------------- |
| 목록                | 작품 카드 `items`, 제목 `title`, 작품 링크 `url`     |
| 작품 정보·회차 목록 | 제목 `title`, 회차 행 `rows`, 본문 링크 `chapterUrl` |
| 소설 본문           | 본문 루트 `root`, 본문 텍스트 `text`                 |
| 웹툰 본문           | 본문 루트 `root`, 본문 이미지 `images`               |

작품·회차 링크는 `href`, 웹툰 이미지는 `imageUrl`입니다. 웹툰 실제 목차 수집은 `expectedChapters` 또는 `episodeCount`의 전체 회차 수와 목차 개수가 일치하는지도 확인합니다. 긴 목차의 **더 보기**·**다음 페이지** 동작을 함께 지정하세요.

### 적용 범위·변경·삭제

- 기본 연결은 **사이트 origin + 소설/웹툰 유형**별로 구분됩니다.
- 웹툰 예약은 생성할 때 서버가 확정한 설정 사본·해시를 보관합니다. 이후 연결을 바꿔도 이미 생성한 예약·실행 중 작업은 기존 사본을 유지합니다.
- 활성 설정을 수정 저장하면 새 설정으로 세 페이지를 다시 확인해야 새 웹툰 예약에서 사용할 수 있습니다. 검증은 설정 해시에 연결되며 시간만으로 자동 만료되지는 않습니다. 사이트가 바뀌면 직접 다시 확인합니다.
- 사용자 웹툰 연결이 없으면 내장 설정을 사용합니다. 사용자 연결의 검증·선택자 오류를 다른 파서로 숨기지 않습니다.
- 삭제하려면 **적용 해제** 후 저장 목록의 **삭제**를 누릅니다. 프리셋 삭제는 기존 작품·수집 파일 삭제가 아닙니다.

## 6. JSON 가져오기·백업과 호환

**설정 JSON 직접 가져오기 · 고급**을 펼칩니다.

- **JSON 파일 불러오기** 또는 **프리셋 JSON (최대 32KiB)** 붙여넣기로 편집 화면에 가져옵니다. 서버 저장 버튼을 눌러 확정합니다.
- **JSON 복사**나 저장 목록의 **JSON 보기**로 확인합니다. 파일 백업은 복사한 JSON을 UTF-8 `.json` 파일에 저장합니다.
- 버전 1의 단일 목록/정보/목차/본문, 버전 2의 소설 세 페이지 설정도 읽습니다. v1은 편집 시 세 페이지 그룹으로 변환합니다. 실행 평가용 변환은 원본 레코드를 자동 덮어쓰거나 활성화하지 않습니다.
- 신규 웹툰은 v3의 `contentType`, `pagePatterns`, `catalogOrder`, 목록 `sources`를 사용합니다. 구형 소설 설정을 그대로 웹툰 설정으로 재사용하지 않습니다.

| 설정 항목        | 제한                                                   |
| ---------------- | ------------------------------------------------------ |
| 저장 개수        | 최대 100개 (기본 복사본 포함)                          |
| 프리셋 JSON      | 최대 32KiB                                             |
| 프리셋 저장 파일 | 최대 2MiB                                              |
| 이름             | 1~80자                                                 |
| 선택자 하나      | 최대 1,024자                                           |
| Shadow DOM 경로  | 최대 8단계                                             |
| v3 페이지 패턴   | 유형당 1~8개, 각 경로 최대 300자                       |
| 원본 origin      | 공개 HTTPS, 사용자명·암호·포트·경로·쿼리·fragment 제외 |

현재 서버 원본 확인은 `sbxh9.com`, `toki32.com`의 지정된 페이지 경로만 허용합니다. 다른 HTTPS origin을 JSON으로 저장할 수 있다고 확인·수집도 지원되는 것은 아닙니다.

### 선택자·개인정보 경계

설정은 CSS 선택자·`shadowPath`·`relativeTo`·속성·반복 여부로 구성됩니다. 열린 Shadow DOM과 렌더러의 유효한 `__novelShadow` root를 지원하며, 접근할 수 없는 closed root와 iframe 내부는 지원하지 않습니다.

`imageUrl`은 `currentSrc` → `data-src` → `src` 순으로 읽습니다. 웹툰 이미지는 본문 루트 안에서 DOM 순서로 평가합니다. URL 확장자가 실제 이미지 형식과 같다고 가정하지 않습니다.

프리셋 JSON에는 선택자 설정만 포함합니다. 본문 표본·이미지 응답·쿠키·로그인 입력·토큰·실행 JavaScript는 저장하지 않습니다. 원본 확인은 원본을 읽지만 결과·검증 기록에는 매칭 개수와 설정 해시를 사용합니다.

서버 파일은 `data/extraction-presets.json`, `data/preset-bindings.json`, `data/preset-validation.json`입니다. 설치 폴더의 `data/`를 기준으로 합니다. 개인 설정·수집 자료를 공개 Git에 올리지 마세요.

## 7. 자주 막히는 부분

| 증상                                       | 확인할 사항                                                 |
| ------------------------------------------ | ----------------------------------------------------------- |
| 북마크 실행이 안 됨                        | 원본 탭·북마크 주소의 `javascript:`·브라우저 정책 확인      |
| 같은 카드 정보만 반복                      | 반복 부모를 먼저 저장하고 내부 항목을 상대 선택자로 재지정  |
| 웹툰 이미지 한 장만 매칭                   | 루트 먼저 고정, 루트 안의 `img`, `imageUrl`, 여러 요소 사용 |
| 저장 연결 만료                             | 로그인 후 현재 북마크 재등록 또는 JSON 가져오기             |
| 확인 버튼 잠김                             | 저장 목록에서 불러오기, 미저장 변경 먼저 저장               |
| 세 페이지 확인 요구                        | 최신 설정으로 목록·정보·본문 모두 확인                      |
| 다른 탭에서는 본문이 보이나 서버 확인 실패 | 별도 확인 컨텍스트의 정상 접근, 필수 선택자·URL 확인        |
| 기존 예약이 예전 설정 사용                 | 예약 당시 사본 유지. 적용 후 새 예약 생성                   |
| 적용한 프리셋 삭제 실패                    | 먼저 적용 해제                                              |
| 소설 수집 결과가 적용 후에도 같음          | 소설 런타임은 현재 내장 파서 사용                           |

## 개발자용 API 참고

관리자 인증과 기존 쓰기 출처 검사를 적용합니다.

| 요청                                         | 기능                                        |
| -------------------------------------------- | ------------------------------------------- | ------ | ------------------------------------------- |
| `GET /api/extraction-presets/defaults`       | 기본 템플릿 목록                            |
| `POST /api/extraction-presets/defaults`      | `{ "defaultId": "..." }`로 독립 복사본 생성 |
| `GET/POST /api/extraction-presets`           | 목록 / 신규 저장                            |
| `GET/PUT/DELETE /api/extraction-presets/:id` | 조회 / 수정 / 삭제                          |
| `POST /api/extraction-presets/:id/validate`  | `{ "pageKind": "listing                     | detail | reader", "url": "실제 HTTPS 주소" }`로 확인 |
| `GET /api/extraction-presets/bindings`       | 유형·origin별 기본 연결과 검증 상태         |
| `PUT /api/extraction-presets/:id/binding`    | 빈 객체 `{}`로 적용                         |
| `DELETE /api/extraction-presets/:id/binding` | 빈 객체 `{}`로 해제                         |

웹툰 예약의 `presetSnapshot`·`presetHash`는 서버가 확정합니다. 클라이언트 임의 사본·해시 제출은 거부하며, 소설 예약에는 현재 이 사본 연결이 적용되지 않습니다.
